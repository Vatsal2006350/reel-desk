Information processed

When Meta sends a comment webhook for a configured Reel, the service processes the comment text, comment ID, Reel ID, commenter’s Instagram-scoped ID (and username if Meta includes it), and the event time. The commenter ID is used only to ignore comments made by the account owner; the service does not store the commenter ID or username. It stores an event record only when the comment matches that Reel’s enabled keyword rule. The record contains up to 1,000 characters of comment text, the comment ID, Reel ID, event time, delivery status, and limited diagnostic detail if delivery fails. The event record prevents duplicate replies and appears in the account owner’s activity view.

The service also stores the Reel owner’s automation rules, including the Reel ID, trigger keywords, reply text, and whether the rule is enabled.

How information is used

Matching comment information is used to send one private reply to that comment through Meta’s Instagram API and to record whether the request was accepted or failed. The service does not use comment information for advertising, profiling, or selling data.

Retention and deletion

Comment event records are set to expire after 30 days. AWS may take additional time to remove expired records. Automation rules remain until the account owner changes or removes them. To request deletion of information held by this service, contact the service operator; the account owner will locate and remove the matching event or rule from the service’s AWS storage. This request does not delete comments or messages held by Instagram.

Service providers and security

Meta provides the Instagram API and delivers the comment events. Amazon Web Services hosts the webhook and stores its configuration and event records. The service uses HTTPS for network requests, AWS Systems Manager SecureString values for credentials, DynamoDB encryption at rest, and authentication for its private dashboard. Information is not sold or shared for another company’s independent marketing.

Cookies and analytics

This policy page does not set cookies or use third-party analytics.

Contact

For privacy questions or deletion requests, contact the account owner using the contact information published by the operator.
